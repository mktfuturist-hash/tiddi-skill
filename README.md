## 무엇을 해 주나요

| 기능 | 하는 일 |
|---|---|
| 🗺️ 용량 지도 | C 드라이브 남은 용량과 폴더 · 유형별 크기를 그림으로 보여 줘요. 칸을 누르면 안쪽 폴더로 들어가요 |
| 🖼️ 스크린샷 짝 | 캡처 도구가 몰래 쌓아 둔 스크린샷 원본과, 내가 이름 붙여 따로 저장한 사본을 "같은 장면"으로 찾아 짝지어요. 지우는 건 원본뿐이에요 |
| 👯 같은 사진 여러 벌 | 내용이 100% 똑같은 사진 · 영상이 여러 폴더에 흩어져 있으면 묶어서 보여 줘요. **묶음마다 하나는 꼭 남겨요** |
| 🗂️ 오래된 파일 | 오랫동안 안 고친 큰 파일을 기간 · 크기 · 종류로 골라 볼 수 있어요 |
| ↩️ 지운 기록 | 휴지통으로 보낸 건 언제든 원래 자리로 되돌려요 |

바탕화면 아이콘을 더블클릭하면 화면 오른쪽 아래에 작은 팝업이 뜨고, 「전체 화면으로」를 누르면 큰 창이 열려요.

## 설치

[Claude Code](https://claude.com/claude-code)에 아래처럼 말하면 돼요.

```
https://github.com/mktfuturist-hash/tiddi-skill
이 스킬 설치해 줘. 다 되면 TIDDI 설치해 줘.
```

스킬이 준비 확인 → 설치 → 바탕화면 아이콘 만들기 → 첫 실행까지 안내해요.

**필요한 것**

- 윈도우 10 · 11 (맥은 안 돼요)
- [Node.js](https://nodejs.org) 20.9 이상 (LTS)
- Microsoft Edge (윈도우에 기본으로 있어요)
- 설치할 때 남은 용량 1GB쯤

## 처음엔 정찰 모드예요

설치하면 **보여 주기만 하고 아무것도 지우지 않는 정찰 모드**로 시작해요. 짝과 같은 사진 묶음을 직접 눈으로 확인한 뒤 Claude에게 "정찰 모드 풀어 줘"라고 하면 휴지통 버튼이 켜져요.

## 지키는 약속

| 약속 | 어떻게 |
|---|---|
| 영구 삭제 없음 | 윈도우 휴지통으로만 보내요. 휴지통이 꺼져 있으면 아무것도 보내지 않아요 |
| 내가 고른 것만 | 자동으로 지우는 기능이 없어요. 보내기 직전에 파일마다 한 번 더 확인해요 |
| 사본은 그대로 | 스크린샷 짝은 원본만, 같은 사진 여러 벌은 묶음마다 하나는 꼭 남겨요 |
| 보호하는 파일 | 최근 7일 파일, 개발 프로젝트(package.json · .git) 안 파일, AppData · 윈도우 · 프로그램 폴더, 휴지통에 남은 자리보다 큰 파일 |
| 인터넷 안 씀 | 이 컴퓨터(`127.0.0.1`)에서만 열리고, 바깥으로 보내는 데이터가 없어요 |
| 돈 안 듦 | 무료 도구만 써요. 계정도 필요 없어요 |

## 데이터는 어디에

설치한 폴더의 `data\`에만 저장돼요 (훑은 결과, 짝 · 같은 사진 묶음, 지운 기록). 사진 자체는 어디에도 복사하지 않아요.

## 만든 것

- Next.js 16 · Tailwind 4 · TypeScript
- 파일 읽기 · 비교 · 휴지통은 윈도우에 기본으로 있는 PowerShell + .NET으로 해요 (추가 프로그램 설치 없음)
- 자세한 구조는 [`app/README.md`](app/README.md), Claude가 읽는 안내는 [`SKILL.md`](SKILL.md)

## 알아 두세요

TIDDI는 휴지통으로만 보내고 보내기 전에 여러 번 확인하지만, **무엇을 보낼지는 쓰는 사람이 직접 확인하고 골라요.** 윈도우 휴지통을 비우기 전에 한 번 더 살펴봐 주세요.

## 이름 뜻

**TIDDI = Tidy files, more space.** 파일을 깔끔하게(tidy) 정리하면 그만큼 공간이 생긴다는 뜻이에요.
