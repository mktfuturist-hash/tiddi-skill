# TIDDI

> **Tidy files, more space.** 파일은 깔끔하게, 공간은 넉넉하게.

용량 경고가 뜰 때 **10분 안에** 끝내는 내 컴퓨터 저장공간 정리 앱. 뭐가 용량을 먹는지 그림으로 보고, 중복과 오래된 파일을 **체크한 것만 휴지통으로** 보내요.

## 여는 법

**바탕화면의 TIDDI 아이콘을 더블클릭**하면 화면 오른쪽 아래에 작은 팝업 창이 떠요.

- 팝업 오른쪽 위 **「전체 화면으로 ↗」**를 누르면 큰 창이 열려요
- TIDDI 창을 다 닫으면 10분 뒤 TIDDI가 스스로 꺼져요 (훑기 · 중복 찾기 중에는 안 꺼져요)
- 인터넷에 올라가지 않아요. 이 컴퓨터(`127.0.0.1:3737`)에서만 열려요

## 쓰는 법

1. **훑기** — 「다시 훑기」를 누르면 드라이브마다 1~3분 동안 읽기만 하고, 용량 지도와 오래된 파일 목록을 만들어요. 드라이브가 여러 개면 홈 위쪽 탭으로 골라 봐요
2. **중복 정리** — 「중복 찾기」로 ① 사본이 있는 스크린샷 원본 ② 내용이 100% 같은 사진 · 영상 여러 벌을 찾고, 체크한 것만 휴지통으로
3. **오래된 파일** — 기간(6개월~3년) · 크기 · 종류로 골라 보고, 체크한 것만 휴지통으로

보낸 건 **「지운 기록」**에서 언제든 되돌릴 수 있어요. 용량은 **윈도우 휴지통을 비운 뒤에** 생겨요.

## 지키는 약속

| 약속 | 어떻게 |
|---|---|
| 영구 삭제 없음 | 윈도우 휴지통으로만 보내요 |
| 내가 고른 것만 | 자동으로 지우는 기능이 없어요. 보내기 직전에 서버가 파일마다 한 번 더 확인해요 |
| 사본은 그대로 | 스크린샷 짝은 원본만, 같은 사진 여러 벌은 **묶음마다 하나는 꼭** 남겨요 |
| 보호하는 파일 | 최근 7일 파일, 개발 프로젝트(package.json · .git) 안 파일, AppData · 윈도우 · 프로그램 · 게임 폴더, 그 드라이브 휴지통에 남은 자리보다 큰 파일 |
| 드라이브 | C 드라이브는 내 사용자 폴더만, D 같은 다른 내장 드라이브는 드라이브 전체(프로그램 · 게임 · 시스템 폴더 빼고)를 봐요. USB · 외장 · 네트워크 · 가상 드라이브는 휴지통이 없을 수 있어서 용량만 보여 줘요 |
| 오래된 파일 기준 | 6개월이 안 된 파일은 보내지 않아요 |
| 인터넷 안 씀 | 바깥으로 보내는 데이터가 없어요 (Next.js 사용 통계도 껐어요) |

## 데이터가 저장되는 곳

`tiddi/data/` 폴더 (git에 올라가지 않아요)

| 파일 | 내용 |
|---|---|
| `scan.json` | 용량 지도 (마지막 훑기 결과) |
| `files.json` | 오래된 파일 후보 (1MB 이상, 경로 · 크기 · 고친 날짜) |
| `pairs.json` | 스크린샷 짝 · 같은 사진 여러 벌 |
| `history.json` | 지운 기록 (되돌리기에 써요) |
| `server.log` · `server-error.log` | 바탕화면 아이콘으로 켰을 때의 서버 기록 |

사진 자체는 어디에도 복사하지 않아요.

## 문제가 생기면

| 이럴 때 | 이렇게 |
|---|---|
| 아이콘을 눌러도 안 열려요 | 몇 초 기다렸다가 다시 더블클릭. 그래도 안 되면 `data\server-error.log`를 Claude에게 보여 주세요 |
| 바탕화면 아이콘이 없어졌어요 | `scripts\install-shortcut.ps1`을 Claude에게 실행해 달라고 하세요 |
| 코드를 고쳤는데 그대로예요 | TIDDI 창을 다 닫고 10분 기다리거나 서버를 끈 뒤, `npm run build`를 하고 다시 여세요 |

## 만든 것 (개발 메모)

- Next.js 16 · Tailwind 4 · TypeScript, `127.0.0.1:3737`에서만 열림
- 실제 파일 일은 윈도우 기본 PowerShell + .NET이 해요 (`scripts/`)
  - `scan.ps1` 드라이브 훑기 · `pairs.ps1` 스크린샷 짝 + 같은 사진 여러 벌 · `trash.ps1` 휴지통으로 · `restore.ps1` 되살리기
  - `launch.vbs` → `launch.ps1` 바탕화면 아이콘 실행기 · `install-shortcut.ps1` 아이콘 만들기 · `make-icon.ps1` 아이콘 그리기
- 화면: `/` 전체 버전, `/mini` 팝업 버전
- 개발할 때: `npm run dev` (같은 3737 포트라 바탕화면 TIDDI는 먼저 꺼 두세요)
